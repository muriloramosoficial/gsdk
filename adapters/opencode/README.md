# OpenCode

Copie `../../skills/game-studio-ai/` para `.opencode/skills/game-studio-ai/`. A documentação também lista `.agents/skills` e `.claude/skills` como locais de compatibilidade, mas isso não torna semântica/recursos idênticos. Agentes em `../../agents/` usam o frontmatter do Claude Code e não devem ser copiados sem conversão/revisão. Servidores MCP são configurados em `mcp.servers` no arquivo OpenCode; nenhum servidor é incluído.

Veja https://opencode.ai/docs/skills/, https://opencode.ai/docs/agents/ e https://opencode.ai/docs/mcp-servers/.
