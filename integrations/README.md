# Integrações MCP

Não há um servidor MCP específico definido pelo projeto do usuário, portanto não incluímos `.mcp.json` ou servidores fictícios. Escolha um servidor real, confira documentação/licença, ferramentas e schemas, configure no cliente/harness e teste uma operação de baixo risco. Mantenha credenciais no gerenciador de segredos/variáveis do cliente. MCP fornece tools/resources/prompts ao host; não cria agentes funcionários nem executa automaticamente as chamadas da API do modelo.

Para Claude Code, Codex e OpenCode, veja os guias oficiais listados em `docs/adapter-matrix.md`.
